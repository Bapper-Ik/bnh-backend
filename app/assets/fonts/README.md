# Bundled PDF fonts

Unmodified Liberation fonts 2.1.5 from Debian package `fonts-liberation` version `1:2.1.5-3`.
Upstream: https://github.com/liberationfonts/liberation-fonts
License: SIL Open Font License 1.1; copyright and redistribution notice in `LICENSE.txt`.

- Liberation Serif Regular: document body and footer.
- Liberation Sans Bold: headings.

These files are included in the backend image and embedded in generated PDFs. No OS font package, network download, proprietary font file or Render font secret is required. Do not remove the copyright/license notice when redistributing the image.
